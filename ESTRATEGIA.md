# Promptfly — Como funciona o sistema de conteúdo

> Pensa exatamente como o Instagram. A lógica é a mesma.

---

## A analogia completa

| Instagram | Promptfly |
|---|---|
| Seu perfil | A landing page (já feita) |
| Seguidores | Inscritos na newsletter |
| Botão "Seguir" | Botão "Assinar newsletter grátis" |
| Feed de posts | E-mails da newsletter |
| Post do feed | Guia / artigo publicado |
| Stories | Dicas rápidas na newsletter |
| Reels virais | Guia que vai pro Google / LinkedIn |
| Bio com link | CTA da landing page → Beehiiv |
| Notificação de novo post | E-mail chegando na caixa do inscrito |
| Explorar / Hashtags | Google (SEO) + compartilhamento |

---

## O fluxo em 5 passos

```
1. PESSOA DESCOBRE
   └── Google ("como fazer prompt para ChatGPT")
   └── Alguém compartilha um guia no LinkedIn
   └── Indicação de amigo
         ↓

2. CHEGA NA LANDING PAGE
   └── Vê o site (já feito, bonito)
   └── Lê a proposta de valor
   └── Clica em "Assinar newsletter grátis"
         ↓

3. VIRA INSCRITO (= seguidor)
   └── Entra no Beehiiv
   └── Recebe e-mail de boas-vindas automático
   └── Fica na lista para receber novos guias
         ↓

4. RECEBE CONTEÚDO TODA SEMANA
   └── 1 guia por semana no e-mail
   └── Lê, aprende, aplica no trabalho
   └── Gosta → compartilha → novos leitores entram no passo 1
         ↓

5. MONETIZAÇÃO (quando tiver audiência)
   └── Patrocínio de empresas de IA (paga por e-mail enviado)
   └── Newsletter paga (tier premium)
   └── Curso / mentoria
```

---

## O que você publica (os "posts")

Cada guia é um "post" do Instagram. Segue sempre o mesmo formato:

```
┌─────────────────────────────────────────────────────┐
│  TÍTULO DIRETO                                      │
│  Ex: "Chain-of-Thought: como fazer a IA raciocinar" │
│                                                     │
│  ① O QUE É (1 parágrafo)                           │
│  ② POR QUE FUNCIONA (1 parágrafo)                  │
│  ③ COMO USAR — passo a passo                        │
│  ④ PROMPT PRONTO PARA COPIAR                        │
│  ⑤ EXEMPLO REAL (antes e depois)                    │
│  ⑥ RESUMO EM 3 PONTOS                              │
└─────────────────────────────────────────────────────┘
```

---

## Rotina semanal (simples)

```
SEGUNDA   → Escolhe o tema do guia da semana
TERÇA     → Escreve o guia (1-2h)
QUARTA    → Revisa + formata no Beehiiv
QUINTA    → Envia para os inscritos
SEXTA     → Posta resumo no LinkedIn com link para o guia
```

Isso é tudo. Uma publicação por semana.

## Como cresce (o "algoritmo")

No Instagram, o algoritmo distribui seu conteúdo.
No Promptfly, o "algoritmo" é o Google + as pessoas compartilhando.

```
Guia bem escrito
    ↓
Google indexa (2-4 semanas)
    ↓
Aparece em buscas de "como usar IA", "prompt ChatGPT", etc.
    ↓
Leitores chegam organicamente
    ↓
Assinam a newsletter
    ↓
Recebem próximos guias
    ↓
Compartilham com colegas
    ↓
Ciclo se repete
```
