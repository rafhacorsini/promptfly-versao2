Todo mundo está usando IA. Mas quase ninguém aprendeu a se comunicar com ela.

A diferença entre um profissional que tira resultados excepcionais da IA e um que fica frustrado com respostas genéricas não é o modelo que usa — é a forma como escreve os prompts.

## O que é um prompt

Um prompt é qualquer instrução que você dá para um modelo de linguagem. Pode ser uma pergunta, um comando, um contexto, um exemplo. Tudo que você escreve antes de apertar enter é um prompt.

O problema é que a maioria das pessoas trata a IA como um mecanismo de busca — fazem perguntas curtas e esperam respostas mágicas. Não é assim que funciona.

## O que é engenharia de prompt

Engenharia de prompt é a prática de **estruturar suas instruções de forma intencional** para obter respostas consistentes, precisas e úteis de modelos de linguagem.

Não é uma habilidade técnica. Não exige saber programar. É uma habilidade de comunicação — como aprender a dar briefings claros para um funcionário.

A diferença é que esse funcionário é incrivelmente capaz, mas só executa exatamente o que você pede. Se você pede mal, ele entrega mal.

## Por que 90% das pessoas usa IA errado

```
❌ Prompt ruim:
"Me ajuda a escrever um e-mail"

✅ Prompt bom:
"Você é um especialista em comunicação executiva.
Escreva um e-mail profissional para um cliente que
atrasou o pagamento. Tom: firme mas cordial.
Extensão: máximo 5 linhas. Não use linguagem agressiva."
```

No primeiro caso, a IA vai inventar um contexto. No segundo, você controla o resultado.

## Os 4 elementos de um prompt eficiente

Todo prompt de alta qualidade tem quatro componentes:

**1. Papel (Role)**
Diga quem a IA deve ser. Isso ativa o contexto certo.
> *"Você é um analista financeiro sênior com 15 anos de experiência..."*

**2. Contexto**
Dê as informações que a IA precisa para responder bem.
> *"Estou preparando uma apresentação para investidores sobre..."*

**3. Tarefa**
Seja específico sobre o que você quer. Verbo + resultado.
> *"Crie um resumo executivo de 3 parágrafos com..."*

**4. Formato**
Diga como quer a resposta.
> *"Responda em tópicos. Máximo 5 linhas por tópico. Sem introdução."*

## O erro mais comum

Deixar a IA preencher os espaços em branco.

Quando você não especifica o tom, ela escolhe um. Quando você não define o tamanho, ela decide. Quando você não dá contexto, ela inventa.

Cada espaço em branco no seu prompt é uma decisão que a IA vai tomar por você — e raramente ela vai tomar a mesma decisão que você tomaria.

## Como aplicar hoje

Pegue o próximo prompt que você ia escrever e adicione:

1. Um papel para a IA
2. Uma frase de contexto
3. O formato exato que você quer

Compare o resultado com o que você obtinha antes.

A diferença vai ser imediata.
