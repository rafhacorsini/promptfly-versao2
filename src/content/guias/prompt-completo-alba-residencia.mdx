Ele é grátis. Cola o prompt abaixo inteiro numa IA (Claude Code, Cursor, o que você usar) e você tem o site completo rodando.

````text
PROMPT (copie a partir daqui)

Quero que você recrie exatamente a landing page descrita abaixo, sem mudar nada: nem cores, nem espaçamentos, nem tempos de animação, nem os links de asset. Copie o código tal como está e organize os arquivos exatamente na estrutura indicada.

Stack obrigatória

- React 19 + TypeScript
- Vite como bundler
- Tailwind CSS v4 (via plugin @tailwindcss/vite, sem arquivo de config separado — tudo em CSS com @theme)
- gsap (com os plugins ScrollTrigger e SplitText — desde 2024 o Club GSAP inteiro é gratuito, incluído no pacote normal)
- lenis — smooth scroll
- lucide-react — ícones
- Fontes locais via @fontsource (Instrument Serif, Bricolage Grotesque, Monsieur La Doulaise) + Bodoni Moda/Italiana via Google Fonts
- Nenhuma outra lib de animação (sem Framer Motion, sem three.js)

O que é a página

Landing de residência de luxo ("Alba — Costa del Sol"), editorial e cinematográfica, organizada em 6 seções + rodapé, quase todas pinadas no scroll:

1. **Hero**: imagem de dia/noite alternável por botão (cross-fade), 3 hotspots interativos sobre a foto (cada um abre um card explicando um detalhe arquitetônico), selo circular rotativo com texto em curva (SVG `textPath`), título "Alba Residência" em `SplitText` por caractere subindo atrás de uma cortina que abre no load, e uma sequência de saída pinada pelo scroll: o texto sai, a foto ganha parallax vertical e um botão de vidro "Ver Apartamentos" aparece.
2. **Apartamentos**: nuvens fotorealistas em múltiplas camadas com deriva horizontal (paralaxe de profundidade) "subindo como cortina" por cima da Hero, **borboletas com chroma-key em tempo real** cruzando a tela (removendo o fundo verde do vídeo ao vivo, via canvas — sem servidor, sem After Effects) em dois voos diferentes (um atravessando a largura toda, outro subindo em diagonal), colunas editoriais "Sobre Nós"/"Conceito" com entrada escalonada, citação autoral com assinatura em fonte script, e um tríptico de materiais com parallax de scroll.
3. **Vídeo de Drone**: seção pinada onde os textos laterais somem e o vídeo central expande via `scale` do GSAP (não largura/altura), revelando um texto de localização abaixo.
4. **Slider de Localização**: seção pinada com 4 slides que deslizam horizontalmente conforme o scroll vertical avança (a rolagem vertical é convertida em deslocamento horizontal via `x: -(scrollWidth - innerWidth)`), terminando num mapa com grid de pontos de distância (aeroporto, marina, golfe etc.) que entram em cascata.
5. **Crepúsculo**: seção pinada com efeito de "lanterna" — uma segunda cópia mais clara da mesma foto só é revelada dentro de um círculo que segue o mouse (`mask-image: radial-gradient` dinâmico), com 3 fases de texto entrando/saindo e um CTA final "Agendar Experiência Privada".
6. **Contato**: título grande com reveal por linha atrás de máscaras, e um cartão de "folha de papel" texturizada com clipe metálico no topo, formulário de 6 campos numerados (incluindo checkboxes customizados de tipo de interesse) que mostra uma tela de confirmação ao enviar.
7. **Rodapé**: colunas de navegação/contato, repetição monumental do título da Hero, e barra de copyright com botão "voltar ao topo".

Toda a tipografia de título usa `font-display` (Instrument Serif), toques manuscritos usam `font-script` (Monsieur La Doulaise), e texto técnico/rótulos usam `font-sans` (Bricolage Grotesque) em uppercase com tracking largo. Responsivo mobile-first: as seções pinadas ajustam posição/direção via `matchMedia('(max-width: 767px)')` dentro do próprio GSAP, não só CSS.

10. src/lib/useSmoothScroll.ts (copiar exatamente)

```typescript
import { useEffect } from 'react'
import gsap from 'gsap'
import ScrollTrigger from 'gsap/ScrollTrigger'
import Lenis from 'lenis'

gsap.registerPlugin(ScrollTrigger)

export function useSmoothScroll() {
  useEffect(() => {
    const lenis = new Lenis({
      duration: 1.2,
      easing: (t) => Math.min(1, 1.001 - Math.pow(2, -10 * t)),
      smoothWheel: true,
    })

    lenis.on('scroll', ScrollTrigger.update)

    const tick = (time: number) => {
      lenis.raf(time * 1000)
    }
    gsap.ticker.add(tick)
    gsap.ticker.lagSmoothing(0)

    return () => {
      gsap.ticker.remove(tick)
      lenis.destroy()
    }
  }, [])
}
```

11. src/components/apartments/GreenScreenVideo.tsx (o coração do efeito de chroma-key — copiar exatamente)

Nota para a IA: este componente NÃO usa nenhuma lib de remoção de fundo. Ele desenha cada frame do vídeo num `<canvas>` 2D e zera o canal alfa de qualquer pixel que seja predominantemente verde — é chroma-key de verdade, rodando 60x por segundo, só com Canvas API.

```tsx
import { useEffect, useRef, useState, type FC } from 'react'

type GreenScreenVideoProps = {
  src: string
  className?: string
}

export const GreenScreenVideo: FC<GreenScreenVideoProps> = ({ src, className }) => {
  const videoRef = useRef<HTMLVideoElement>(null)
  const canvasRef = useRef<HTMLCanvasElement>(null)
  const [shouldLoad, setShouldLoad] = useState(false)

  useEffect(() => {
    const canvas = canvasRef.current
    if (!canvas) return

    const observer = new IntersectionObserver(
      (entries) => {
        if (entries[0]?.isIntersecting) {
          setShouldLoad(true)
          observer.disconnect()
        }
      },
      { rootMargin: '600px' },
    )

    observer.observe(canvas)
    return () => observer.disconnect()
  }, [])

  useEffect(() => {
    if (!shouldLoad) return

    const video = videoRef.current
    const canvas = canvasRef.current
    if (!video || !canvas) return

    const ctx = canvas.getContext('2d', { willReadFrequently: true })
    if (!ctx) return

    canvas.width = 480
    canvas.height = 270

    const tryPlay = () => {
      video.play().catch(() => {})
    }

    video.addEventListener('loadeddata', tryPlay)
    video.addEventListener('canplay', tryPlay)
    if (video.readyState >= 2) tryPlay()

    let raf = 0

    const render = () => {
      if (video.readyState >= 2) {
        ctx.drawImage(video, 0, 0, canvas.width, canvas.height)
        const frame = ctx.getImageData(0, 0, canvas.width, canvas.height)
        const data = frame.data
        for (let i = 0; i < data.length; i += 4) {
          const r = data[i]
          const g = data[i + 1]
          const b = data[i + 2]
          if (g > 85 && g > r * 1.3 && g > b * 1.3) {
            data[i + 3] = 0
          }
        }
        ctx.putImageData(frame, 0, 0)
      }
      raf = requestAnimationFrame(render)
    }

    render()

    return () => {
      cancelAnimationFrame(raf)
      video.removeEventListener('loadeddata', tryPlay)
      video.removeEventListener('canplay', tryPlay)
    }
  }, [shouldLoad])

  return (
    <>
      {shouldLoad && (
        <video
          ref={videoRef}
          src={src}
          autoPlay
          loop
          muted
          playsInline
          crossOrigin="anonymous"
          className="pointer-events-none fixed left-0 top-0 h-px w-px opacity-0"
        />
      )}
      <canvas ref={canvasRef} className={className} />
    </>
  )
}
```
````
