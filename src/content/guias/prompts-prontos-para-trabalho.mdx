Sem teoria. Só prompts que funcionam.

Cada um foi testado nos principais modelos (GPT-4o, Claude, Gemini) e entrega resultados consistentes. Copie, substitua os campos entre `[colchetes]` e use.

---

## 1. E-mail profissional difícil

```
Você é especialista em comunicação executiva.
Escreva um e-mail para [nome/cargo] sobre [assunto].
Contexto: [o que aconteceu ou precisa acontecer].
Tom: [firme e direto / cordial mas assertivo / empático].
Extensão: máximo [X] linhas.
Não use: frases de abertura genéricas, jargão corporativo.
```

---

## 2. Resumo de reunião

```
Você é um assistente executivo sênior.
A seguir está a transcrição de uma reunião:

[cole a transcrição]

Gere:
1. Resumo em 3 bullet points (o que foi decidido)
2. Lista de ações com responsáveis e prazos
3. Próximos passos para a próxima reunião
Formato: markdown limpo.
```

---

## 3. Análise de concorrente

```
Analise [empresa concorrente] sob a perspectiva de [minha empresa/produto].
Estruture a análise em:
- Pontos fortes deles que precisamos observar
- Pontos fracos que podemos explorar
- O que eles fazem melhor que nós hoje
- Uma oportunidade clara que está sendo ignorada por eles
Base sua análise em: [inclua qualquer dado que você tenha]
```

---

## 4. Feedback construtivo para colaborador

```
Você é um gestor experiente com foco em desenvolvimento de pessoas.
Preciso dar feedback para [nome] sobre [situação/comportamento].
O que aconteceu: [descreva]
O impacto: [qual foi o efeito no time/projeto]
O que quero que mude: [comportamento desejado]
Escreva o feedback de forma direta mas construtiva, sem suavizar demais.
```

---

## 5. Proposta comercial

```
Você é um especialista em vendas B2B.
Escreva uma proposta comercial para [prospect] propondo [solução/produto].
Problema deles: [descreva o problema que você resolve]
Nossa solução: [descreva brevemente]
Diferenciais: [liste 3]
Próximo passo proposto: [ex: reunião de 30 minutos]
Tom: confiante, focado em valor, sem excesso de adjetivos.
```

---

## 6. Post para LinkedIn com autoridade

```
Escreva um post para LinkedIn sobre [tema/aprendizado/opinião].
Meu ponto de vista: [o que você quer dizer]
Por que isso importa para meu público ([cargo/área]): [contexto]
Estrutura: gancho de 1 linha → desenvolvimento em 3-4 parágrafos → CTA.
Tom: direto, sem clichês motivacionais, como conversa entre profissionais.
Máximo 1.300 caracteres.
```

---

## 7. Agenda de reunião eficiente

```
Crie uma agenda para uma reunião de [duração] sobre [objetivo].
Participantes: [liste os cargos/áreas]
Decisão que precisa ser tomada ao final: [qual é]
Formato: cada item com tempo estimado e responsável por conduzir.
```

---

## 8. Diagnóstico de problema

```
Você é um consultor sênior em [área].
Problema que estou enfrentando: [descreva]
O que já tentei: [liste]
Contexto da empresa/situação: [dê contexto]
Faça um diagnóstico: qual é a causa raiz mais provável e quais são as 3 ações mais diretas para resolver?
```

---

## 9. Simplificar texto técnico

```
Reescreva o texto abaixo para ser compreendido por [público-alvo: ex. diretores sem background técnico].
Mantenha a precisão das informações, mas elimine jargão desnecessário.
Use analogias quando ajudar a explicar.
Texto original:
[cole o texto]
```

---

## 10. Planejamento de projeto

```
Você é um gerente de projetos sênior.
Preciso criar um plano para: [descreva o projeto]
Prazo: [data]
Time disponível: [quantas pessoas, dedicação]
Restrições: [orçamento, tecnologia, dependências]
Gere: lista de fases, principais entregáveis por fase e riscos que devo monitorar.
```
