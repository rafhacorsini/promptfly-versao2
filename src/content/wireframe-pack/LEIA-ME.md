# Promptfly Wireframe Pack

Wireframes prontos para você mandar para a IA. Você escolhe um, envia a imagem junto com um pedido curto e a IA monta o site seguindo a estrutura.

## O que vem na pasta

| Pasta ou arquivo | Para quê |
|---|---|
| wireframes/ | As imagens dos wireframes. É isto que você manda para a IA |
| exemplos/ | Os sites que a IA montou a partir de cada wireframe, para você comparar |
| PROMPTS.md | Os pedidos prontos para copiar e colar junto com a imagem |
| LEIA-ME.md | Este resumo |

## Como usar em 3 passos

1. **Escolha um wireframe** na pasta wireframes. Olhe o exemplo correspondente para ver o que dá para criar.
2. **Mande a imagem para a IA** (Claude, ChatGPT ou Gemini) junto com um pedido do arquivo PROMPTS.md. Troque o tema pelo do seu projeto.
3. **Ajuste.** Peça para a IA comparar o resultado com o wireframe e corrigir o que ficou fora do lugar.

## Como ler um wireframe

- Blocos escuros com o ícone de montanha são **imagens**.
- Barras cinza são **textos** (a largura mostra se é título ou parágrafo).
- Pílulas e retângulos pequenos são **botões** e **links**.
- Círculos são **botões redondos**, selos ou ícones.

O wireframe só diz **onde** cada coisa fica. Cor, fonte e estilo você define no pedido ou com o Design Pack (DESIGN.md e ANTI_PATTERNS.md), que também é grátis em https://promptfly.com.br/design-pack
