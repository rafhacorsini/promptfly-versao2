# PROMPTS.md

Copie o pedido, troque o que está entre colchetes e mande junto com a imagem do wireframe.

## 1. Pedido básico

```text
Crie um site seguindo exatamente a estrutura deste wireframe, bloco por bloco, na mesma ordem e na mesma posição.
Os blocos escuros com ícone de imagem são imagens, as barras cinza são textos, as pílulas são botões e os círculos são botões redondos ou selos.
O tema do site é: [DESCREVA O SEU PROJETO].
Escreva textos reais em português. Não use lorem ipsum. Se faltar alguma informação, pergunte antes de inventar.
```

## 2. Com o Design Pack (o resultado fica bem melhor)

```text
Antes de começar, leia DESIGN.md e ANTI_PATTERNS.md.
Crie um site seguindo exatamente a estrutura deste wireframe, bloco por bloco.
Use só os tokens do DESIGN.md para cor, fonte, raio e espaçamento.
O tema do site é: [DESCREVA O SEU PROJETO].
```

## 3. Revisar contra o wireframe

```text
Compare o site que você criou com o wireframe anexado.
Liste tudo que está fora de posição, fora de ordem ou faltando.
Depois corrija, sem mudar o que já está igual.
```

## 4. Versão para celular

```text
Agora faça a versão para celular (360px). Mantenha a mesma ordem dos blocos do wireframe, empilhados em uma coluna.
Sem rolagem horizontal.
```

## 5. Trocar só o tema

```text
Mantenha exatamente a estrutura deste wireframe, mas troque o tema para: [NOVO TEMA].
Troque textos, imagens e nomes. Não mude o layout.
```
